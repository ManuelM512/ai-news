### 4. SIRIN: Unified Toolkit for Detecting Contextual Hallucinations in RAG and Memory-Grounded LLMs
**Source:** [arXiv 2608.00033](https://arxiv.org/abs/2608.00033)

SIRIN (Semantic Inconsistency Recognition and Inspection Nexus) is a new open toolkit and interactive web UI that unifies three hallucination-detector paradigms — representation probing, uncertainty estimation, and judge-style verification — alongside pre-generation query answerability, all under one interface and evaluation pipeline. It supports both white-box and black-box LLM settings, provides response- and span-level inspection, and includes a lightweight plug-in architecture for adding new detectors. **Why it matters:** As RAG and long-term-memory agents proliferate, hallucination detection has become a production-critical concern; SIRIN lowers the barrier to rigorous, multi-method evaluation instead of relying on a single opinionated scorer.
