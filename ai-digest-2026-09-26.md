## 1. New Agent Tool · Dataiku Launches Agent Management for Enterprise AI

**Source:** [Dataiku](https://www.dataiku.com/company/news/dataiku-agent-management-general-availability) · [HelpNet Security](https://www.helpnetsecurity.com/2026/09/25/dataiku-agent-management/) · [BigDATAwire](https://www.hpcwire.com/bigdatawire/this-just-in/dataiku-unveils-agent-management-to-track-enterprise-ai-agents-across-platforms/)

Dataiku announced **Agent Management**, a standalone product that inventories AI agents running across major platforms (AWS Bedrock, Databricks, Google Vertex, Copilot Studio, Azure Foundry, Agentforce, Cortex) regardless of which tool built them. It tracks business KPIs and technical performance, tiers agents by risk level, and supports scheduled compliance re-certification.

**Why it matters:** Fewer than one in five organizations maintain a complete inventory of their deployed AI agents — a growing governance gap as agentic systems proliferate. Dataiku's cross-platform coverage makes it a rare vendor-agnostic option. GA is planned for October 2026.

## 4. Research · "Safeguarding LLM Agents against Long-Horizon Threats via Shadow Memory"

**Source:** [arXiv / ACM CCS 2026](https://arxiv.org/list/cs.AI/current)

Accepted at **ACM CCS 2026** (September 23), this paper introduces *Shadow Memory* — a secondary memory store that runs alongside an agent's main context and tracks potential long-horizon adversarial manipulations (e.g., prompt injection across multi-turn sessions). The technique enables detection and quarantine of compromised reasoning chains without halting execution.

**Why it matters:** Security for long-running agents is a largely unsolved problem. As agents operate autonomously across hours-long tasks, a principled memory-level defense is a meaningful step toward safe deployment in high-stakes settings.

## 5. New Framework · LangGraph Passes 1.2 Milestone — Focus on Durable Execution

**Source:** [Shakudo Blog](https://www.shakudo.io/blog/top-9-ai-agent-frameworks) · [AI Agent News](https://aiagentstore.ai/ai-agent-news/this-week)

**LangGraph 1.2** has reached general availability with a focus on **durable execution** and stateful, long-running workflows. Key additions include checkpointing, resilient task queues, and improved support for human-in-the-loop interruptions in multi-step agent graphs.

**Why it matters:** The move to durable execution addresses one of the biggest blockers for production agent deployments — partial failure recovery. LangGraph 1.2 narrows the gap between research prototypes and reliable agentic systems.

## 6. New Model · OpenAI Releases GPT-6 Sol and GPT-6 Luna

**Source:** [TechCrunch](https://techcrunch.com/2026/09/22/openai-launches-gpt-6-sol-and-luna/) · [GitHub Changelog](https://github.blog/changelog/2026-09-22-openais-gpt-6-sol-and-gpt-6-luna-now-available/) · [DataNorth](https://datanorth.ai/news/openai-launches-gpt-6-sol-and-luna)

Released September 22, OpenAI's **GPT-6 Sol** ($2/M input · $10/M output) and **GPT-6 Luna** ($0.10/M · $0.50/M) are the lower-cost tiers of the GPT-6 family. Both carry a 1,050,000-token context window. Sol targets agentic coding workflows; Luna is the cheapest option for high-volume, fast tasks. Both are roughly **half the price** of their GPT-5.6 equivalents.

**Why it matters:** Price reductions of this magnitude (2× vs. the tier they replace) accelerate adoption across startups and enterprises. Luna's sub-cent pricing opens GPT-6-class performance to use cases that previously required smaller, weaker models.

## 7. New Agent Tool · Google ADK for Kotlin 1.0 — On-Device AI Agents

**Source:** [Google Developers Blog](https://developers.googleblog.com/announcing-adk-for-kotlin-10-building-production-ready-ai-agents-in-kotlin-android-and-beyond/) · [InfoQ](https://www.infoq.com/news/2026/09/google-adk-1-0-released/)

Google released **ADK for Kotlin 1.0** (September 9, GA this month), reaching feature parity with the Python ADK while adding Android-native capabilities: on-device inference via LiteRT-LM and ML Kit (beta), Firebase AI Logic for hybrid cloud/on-device orchestration, and Room/AppSearch for persistent agent state. Built on Kotlin Multiplatform, it targets JVM servers and Android equally.

**Why it matters:** On-device agents that can run without a network call open new use cases in privacy-sensitive domains (healthcare, finance) and low-connectivity environments. Google now has a first-class path from server-side agent to mobile edge agent in a single framework.

## 9. Research · CORAL: Self-Evolving Multi-Agent Systems via Shared Persistent Memory

**Source:** [arXiv](https://arxiv.org/list/cs.MA/recent) · [VoltAgent curated papers](https://github.com/VoltAgent/awesome-ai-agent-papers)

**CORAL** introduces a multi-agent architecture where agents share a persistent memory store and evolve their behaviors asynchronously through heartbeat-based interventions. The system achieves **3–10× higher improvement rates** over fixed evolutionary-search baselines on long-horizon benchmarks, without requiring centralized supervision.

**Why it matters:** Autonomous self-improvement in multi-agent systems is a key open research question. CORAL's memory-sharing approach decouples agent learning from global coordination overhead, offering a scalable path toward agents that improve through collective experience.
