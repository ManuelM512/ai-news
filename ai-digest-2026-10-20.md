## New Agent Tool

### Perplexity Open-Sources SPACE — Firecracker-Based Agent Sandbox
**Source:** [Perplexity blog](https://hub-prod.perplexity.ai/hub/blog/secure-sandboxes-for-agents) · [RuntimeWire](https://runtimewire.com/article/perplexity-open-sources-space-agent-sandbox)

Perplexity released SPACE under Apache 2.0 on October 15. Each agent task runs in its own Firecracker microVM, with pause/resume, session forking, rolling snapshots, and per-session credential isolation. Matters because it gives the broader community a production-grade, open-source sandbox architecture that already handles millions of sessions per day at Perplexity—median startup latency 60 ms.

---

### Microsoft Guardian Agents in Project Perception
**Source:** [Unite.AI](https://www.unite.ai/microsoft-adds-guardian-agents-to-project-perception-for-ai-insider-risk/) · [AI Agents News Oct 20](https://aiagentstore.ai/ai-agent-news/today)

Microsoft added guardian-style agents to Project Perception on October 19 that continuously supervise other agents' actions for insider-risk and policy violations inside Microsoft 365 E7. Matters because it is one of the first enterprise deployments of meta-agents whose sole job is watching and auditing other agents in real time.

### Notion Agent Harness — 24+ Hour Task Duration
**Source:** [AI Agent News Today — October 20, 2026](https://aiagentstore.ai/ai-agent-news/today)

Notion's agent harness now supports tasks that run continuously for more than 24 hours, up from its previous shorter session limits. Matters because long-horizon autonomous tasks (end-to-end document research, multi-step project management) have been blocked by short session ceilings across most productivity tools.
