## New Model

### 1. Alibaba Launches Qwen4-Max: Closed-Weight Flagship with 1M-Token Context
**Source:** [Alibaba Cloud Press Room](https://www.alibabacloud.com/press-room/alibaba-unveils-qwen4-max) · [TechNode](https://technode.com/2026/11/16/alibaba-launches-qwen4-max-with-lower-api-prices-and-a-million-token-context-window/) · Nov 16, 2026

Alibaba released Qwen4-Max as an API-only model through QwenCloud, following a limited preview. The model uses a new MoE architecture with native vision support, a 1-million-token context window, and an estimated 2.4 trillion total parameters. Alibaba says the average cost per task is 60% lower than its predecessor, though that figure is unverified.

**Why it matters:** Qwen4-Max is Alibaba's sharpest bid for the closed-model tier dominated by OpenAI and Anthropic. Keeping the weights proprietary — a first for a flagship Qwen release — signals that Alibaba is differentiating its top model by API capability and pricing rather than openness, while smaller open Qwen4 variants are still planned.

## New Agent Tool

### 2. Databricks Opens Genie ZeroOps to Public Beta
**Source:** [Databricks Blog](https://www.databricks.com/blog/introducing-genie-zeroops) · [Unite.AI](https://www.unite.ai/?p=527517) · Nov 19, 2026

Databricks opened Genie ZeroOps to public beta after a private preview that processed over 80,000 real customer incidents. The agent monitors data jobs and tables, diagnoses failures, and proposes fixes as Git-backed pull requests — but requires human approval before any change reaches production. New features include shared issue inboxes, notification summaries, custom instructions, and one-click PR creation.

**Why it matters:** Genie ZeroOps automates the most time-consuming part of data engineering on-call: triaging pipeline failures and writing the fix. Requiring human approval keeps it inside organisational change-management norms, making it one of the more enterprise-deployable autonomous data-ops agents to date.

### 3. LangChain LangSmith Sandboxes Now Generally Available
**Source:** [LangChain Blog](https://www.langchain.com/blog/langsmith-sandboxes-generally-available) · [Introducing Post](https://www.langchain.com/blog/introducing-langsmith-sandboxes-secure-code-execution-for-agents)

LangChain has moved LangSmith Sandboxes to general availability after a private preview that began in March 2026. Each sandbox is a microVM with its own kernel, targeting kernel-level isolation for untrusted model-generated code. The GA release adds Snapshots (copy-on-write forks), Blueprints (pre-warmed environments), a Sandbox CLI, and an Auth Proxy. p50 startup latency is under 1 second.

**Why it matters:** Secure, fast code execution is the missing primitive for deploying coding agents in production. By providing hardware-isolated microVMs with sub-second cold starts and deep LangSmith tracing integration, LangChain closes the gap between agent prototypes and reliable, auditable deployments.

### 4. Microsoft Agent 365 Surpasses 50 Million Registered Agents
**Source:** [Microsoft Tech Community](https://techcommunity.microsoft.com/blog/agent-365-blog/whats-new-in-microsoft-agent-365-ignite-2026/4571753) · [Azure Foundry Docs](https://learn.microsoft.com/azure/foundry/agents/concepts/agent-365-integration) · Nov 17, 2026

A Microsoft blog post at Ignite 2026 reports that organizations have registered more than 50 million agents in Microsoft Agent 365 since its May 2026 launch. The update also expands Agent 365 connectivity to Salesforce Agentforce, Amazon AgentCore, Google Vertex AI, Databricks, and Snowflake. Each agent receives a first-class Microsoft Entra Agent ID, and Azure Foundry provisions and manages agent identities through the full agent lifecycle.

**Why it matters:** Reaching 50 million registered agents in six months illustrates how quickly enterprises are deploying AI agents at scale. Cross-platform identity federation across all major AI clouds turns Entra Agent ID into a potential de-facto standard for multi-cloud agent governance — a significant ecosystem lock-in play for Microsoft.

## Research

### 5. arXiv Digest: Adaptive Inference Schedules for Diffusion Language Models
**Source:** [ArXiv Agents Radar Digest 2026-11-20](https://github.com/kouweizhu/agents-radar/issues/1046) · arXiv 2611.xxxxx · Nov 20, 2026

Researchers propose adaptive inference schedules for diffusion language models, dynamically adjusting the number of denoising steps per token or span based on task difficulty. The paper demonstrates that most tokens in natural language can be decoded with far fewer steps than the standard fixed schedule, improving throughput by up to 3× at comparable quality on standard benchmarks.

**Why it matters:** Diffusion-based language models are a promising alternative to autoregressive generation for latency-sensitive applications. Making inference costs proportional to task difficulty is a critical step toward making them competitive with transformer-based models in real-world deployment, where most queries are routine but occasional hard queries must still be handled gracefully.

## Other

### 6. OpenAI Agent Builder Retires November 30 — Developers Directed to AgentKit
**Source:** [OpenAI Community](https://community.openai.com/t/deprecation-notice-agent-builder/1382650/1) · [OpenAI AgentKit](https://openai.com/index/introducing-agentkit/) · Nov 30 deadline

OpenAI's no-code Agent Builder platform will stop accepting new traffic on November 30, 2026. The official migration path is AgentKit, the code-first Agents SDK. Existing Agent Builder workflows can be exported as Python or TypeScript. For non-developers, OpenAI points to ChatGPT Workspace Agents, which create and deploy agents through natural language. ChatKit self-hosted deployments that use the Agents SDK backend are unaffected.

**Why it matters:** The wind-down signals OpenAI's bet that the agent-building workflow is shifting toward code-first tooling rather than visual builders, at least at the developer tier. The move leaves a gap for platforms like Zapier, n8n, and Microsoft's Copilot Studio that target less technical builders and may now absorb displaced Agent Builder users.

### 7. EU Digital Fairness Act Introduces First Targeted Rules for AI Shopping Agents
**Source:** [MLex / William Fry Alert](https://www.mlex.com/mlex/articles/2548994) · [TechJack Solutions](https://techjacksolutions.com/?p=108598) · Nov 11, 2026

The European Commission proposed the Digital Fairness Act on November 11, with Article 26 specifically governing AI agents that conclude contracts on consumers' behalf. The proposal would require traders to give consumers an express choice over how much authority agents hold, let consumers set purchasing limits, and require approval for individual transactions above a threshold. Financial services are excluded from Article 26's scope in the current text. The proposal moves next to the European Parliament and Council for negotiation.

**Why it matters:** This is the first EU regulatory proposal to directly address commercial AI agents operating autonomously on behalf of consumers. If enacted, it will impose friction on agentic e-commerce flows — but also establish a clear compliance framework that could accelerate enterprise adoption of shopping agents in regulated markets.
