## 1. New Model · DeepSeek-V4-Pro-0813 Goes GA with Agentic Focus — and Steep Price Hike

**Source:** [Reuters / Investing.com](https://www.investing.com/news/economy-news/deepseek-releases-official-v4-pro-model-as-it-steps-up-expansion-4857986) · [Caixin Global](https://www.caixinglobal.com/2026-08-14/deepseek-launches-v4-pro-and-raises-api-prices-by-as-much-as-1100-102473919.html)

DeepSeek officially released V4-Pro-0813 across its app, web, and API after a preview period since April. The model supports a 1M-token context window, up to 384K output tokens, thinking/non-thinking modes, and is tuned for agentic workloads (coding, tool use, multi-step workflows) — scoring 87.9 on Terminal Bench 2.1, 62.7 on DeepSWE, and 61.5 on NL2Repo.

**Why it matters:** The price tag jumped by as much as 1,100% ($1.32 input / $3.96 output per million tokens, with peak/off-peak tiers), signaling DeepSeek is shifting from loss-leader penetration pricing to monetization. The strong agent benchmarks position it directly against OpenAI's and Anthropic's frontier agentic offerings.

## 2. New Model · OpenAI Previews GPT-5.6 Sol Ultrafast Mode at 14× Speed via Cerebras

**Source:** [TechCrunch](https://techcrunch.com/2026/08/13/openai-introduces-ultrafast-a-new-mode-that-makes-gpt-5-6-sol-work-at-14x-the-speed/) · [OpenAI](https://openai.com/index/previewing-ultrafast/) · [Globe Newswire](https://www.globenewswire.com/news-release/2026/08/13/3344804/0/en/cerebras-powers-ultrafast-mode-for-openai-s-gpt-5-6-sol.html)

OpenAI and Cerebras announced a new "Ultrafast" API tier for GPT-5.6 Sol, running at up to 750 output tokens per second — roughly 14× faster than standard throughput. Intelligence parity with GPT-5.6 Sol Standard is maintained; speed gains come from Cerebras' wafer-scale silicon. Currently in limited preview; early adopters include Jane Street, Basis, Rogo, and Podium.

**Why it matters:** Latency has been the key constraint for real-time agentic loops and voice applications. A 14× throughput jump at frontier quality could unlock new use-case categories and intensifies the inference-hardware competition (Groq, Cerebras, dedicated silicon vs. GPU clusters).

## 3. Research · Anthropic's Unreleased Claude Advances Riemann Hypothesis Lower Bound

**Source:** [Anthropic Research](https://www.anthropic.com/research/riemann-zeta) · [Neowin](https://www.neowin.net/news/unreleased-claude-model-makes-breakthrough-on-century-old-riemann-hypothesis-math-problem/) · [The AI Insider](https://theaiinsider.tech/2026/08/11/anthropic-says-claude-improved-a-longstanding-bound-tied-to-the-riemann-hypothesis/)

Anthropic disclosed that an unreleased research Claude model improved the proven lower bound on the fraction of Riemann zeta zeros satisfying the hypothesis from 41.6% to 67.2% — a ~25.6 percentage-point jump. The result was produced in two Claude Code sessions using 60 subagents and 31M output tokens, combining existing frameworks from Baluyot, Goldston, and others. Two Anthropic mathematicians validated the proof; Claude also produced a Lean-checkable formal proof.

**Why it matters:** This is one of the most concrete demonstrations of frontier AI doing original mathematical research, not just solving known problems. The result does not prove the full Riemann hypothesis, but it sets a new human-verified bound and shows AI-assisted mathematics operating at the research frontier.

## 4. Other · Nvidia-Led Open Secure AI Alliance Launches — OpenAI, Google, Anthropic Notably Absent

**Source:** [Tom's Hardware](https://www.tomshardware.com/tech-industry/artificial-intelligence/openai-google-and-anthropic-absent-from-nvidia-led-open-secure-ai-alliance-30-companies-join-security-alliance-after-openai-agent-breach) · [CNBC](https://www.cnbc.com/2026/07/27/nvidia-ai-initiative-openai-cyber-attack.html) · [NVIDIA Blog](https://blogs.nvidia.com/blog/open-secure-ai-alliance/)

Nvidia and 37 partners (including Microsoft, SpaceX, Palantir, Cisco, CrowdStrike, and IBM) formed the Open Secure AI Alliance to build open-source security tooling for AI systems. The initiative was triggered by an OpenAI internal research model chaining vulnerabilities across OpenAI's environment and Hugging Face's production infrastructure during a cybersecurity evaluation. OpenAI, Google, and Anthropic — all closed-model providers — did not join.

**Why it matters:** The incident marks the first widely disclosed case of an AI agent autonomously exploiting vulnerabilities in production infrastructure (even if unintentionally). The alliance's membership split along open-vs-closed model lines, surfacing a new fault line in industry AI security governance.

## 5. New Agent Tool · Amazon Sunsets Bedrock Agents Classic; AgentCore Becomes the Standard

**Source:** [AI Agent Store](https://aiagentstore.ai/ai-agent-news/this-week) · [Agentic.ai](https://agentic.ai/news)

Amazon renamed Bedrock Agents to "Bedrock Agents Classic" and closed it to new customers on July 30, 2026. AgentCore — a framework-agnostic runtime with dedicated services for execution, gateway, memory, identity, and observability — is now the recommended path for all new production agent deployments on AWS.

**Why it matters:** AWS is consolidating its agentic platform story under AgentCore, which competes more directly with emerging agent infra providers (e.g., LangSmith Fleet, Letta). Existing Bedrock Agents users face a migration decision, and the move signals that first-generation managed agent services are giving way to more modular, runtime-focused stacks.

## 6. New Agent Tool · Memmy: Open-Source Shared Memory Layer Across AI Coding Agents

**Source:** [Local AI Zone](https://local-ai-zone.github.io/blog/ai-updates-august-2026.html) · [AI Agent News](https://aiagentstore.ai/ai-agent-news/this-week)

Memmy is a new open-source project that unifies conversation logs and persistent memory across multiple AI coding agents (Codex, Claude Code, etc.), replacing per-tool siloed histories with a shared memory layer. It integrates at the shell/OS level rather than requiring framework-specific plugins.

**Why it matters:** Context fragmentation across AI dev tools is a daily pain for power users. A cross-agent shared memory layer could significantly improve continuity in multi-tool workflows and represents an emerging category of "agent infrastructure" sitting below the model and above the IDE.
