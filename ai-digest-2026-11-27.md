# AI News Digest — 2026-11-27

## Research

### 1. Google Cogentic AI Publishes Six Math Papers in One Day
**Source:** [RD World Online](https://www.rdworldonline.com/google-cogentic-ai-integer-factoring-bounds-lean-proofs/) · [Emergent.sh](https://emergent.sh/news/google-cogentic-ai-releases-6-math-papers-one)

Google Research released six mathematics papers via GitHub on November 25, all produced autonomously by Cogentic, its multi-agent system running on Gemini 4. The lead paper claims a randomized Las Vegas algorithm for integer factoring running in expected time L_N[1/3, 105] — a bound sought in the field since 1992 — with each prime factor verified deterministically via AKS primality testing. The other five papers address discrete logarithms in fixed-characteristic fields, Nash equilibrium approximation, the log-rank conjecture, and Harary's edge reconstruction conjecture.

**Why it matters:** If the factoring claim survives peer review, it would be the most significant theoretical result in computational number theory in decades. The papers are still pending peer review and Lean 4 formalizations are incomplete; cryptographers note it does not immediately break RSA, but the volume and speed of output marks a milestone for AI-driven autonomous research.

## New Model

### 2. Claude Fable 5.2 and Mythos 5.2 Released (Anthropic)
**Source:** [Claude release timeline](https://github.com/jqueryscript/anthropic-claude-timeline) · [Taskade blog](https://www.taskade.com/blog/claude-release-dates)

Anthropic released Claude Fable 5.2 on November 9, 2026, alongside its restricted-access sibling Claude Mythos 5.2. Both models are reported to run ~30% faster than their 5.1 predecessors and are priced at $8/M input tokens and $40/M output tokens. Mythos 5.2 is the same underlying model but with reduced safety restrictions for approved organizations in sensitive research domains.

**Why it matters:** Fable 5.2 is now Anthropic's standard frontier model; the paired Mythos release continues the pattern of making a less-restricted version available to vetted institutions, which matters for AI safety research on dual-use capabilities.

## New Agent Tool

### 6. LangSmith Tool Gateway Enters Public Beta
**Source:** [AI Agent Store](https://aiagentstore.ai/ai-agent-news/this-week)

LangSmith launched its Tool Gateway in public beta on November 19, 2026. The service centralizes credentials, caller identity, access policies, approval flows, and audit traces for every tool call made by an MCP-compatible agent — without requiring changes to the agent itself.

**Why it matters:** As multi-agent deployments move to production, governance of tool access becomes a critical missing layer; Tool Gateway fills that gap and positions LangSmith as the control plane for agentic workflows alongside its existing observability stack.

### 7. Databricks Genie ZeroOps Public Beta
**Source:** [AI Agent Store](https://aiagentstore.ai/ai-agent-news/this-week)

Databricks launched Genie ZeroOps in public beta on November 19, 2026. The agent monitors Databricks jobs and Delta tables, diagnoses failures using Unity Catalog metadata and lineage, and proposes fixes as pull requests — with human approval required before any change is applied.

**Why it matters:** Autonomous data pipeline remediation reduces on-call burden for data engineers; the human-in-the-loop approval step addresses the trust gap that has slowed enterprise adoption of agentic automation in production data systems.

## New Framework

### 8. Tether 0.4.0 Adds Agent Test Harness
**Source:** [AI Agent Store](https://aiagentstore.ai/ai-agent-news/this-week)

Tether 0.4.0, released November 22, 2026, adds a test harness that records and replays agent runs. Developers can assert which tools were called, inspect final file state, and verify that the agent respected step and cost budgets — all without running live API calls during CI.

**Why it matters:** Deterministic replay testing for agents is an unsolved problem in most frameworks; Tether's approach lowers the cost of regression testing for agentic code and makes it feasible to include agents in standard CI pipelines.

## Other

### 9. OpenAI Agent Builder Shuts Down November 30
**Source:** [OpenAI Deprecations](https://developers.openai.com/api/docs/deprecations) · [Refonte Learning](https://www.refontelearning.com/blog/openai-agent-builder-shutdown-vendor-lock-in)

OpenAI's no-code Agent Builder reaches end-of-life on November 30, 2026. Any agent built in Agent Builder will stop functioning unless migrated to the Agents SDK or ChatGPT Workspace Agents. The deprecation was announced June 3, 2026, giving teams roughly six months to migrate.

**Why it matters:** Developers who built internal tools on Agent Builder without an exit plan have days to act; the forced migration also signals OpenAI's shift away from low-code tooling toward the programmatic Agents SDK as the canonical platform.

### 10. Palo Alto Networks to Acquire Applied Compute for ~$4.5B
**Source:** [AI Funding Tracker](https://aifundingtracker.com/ai-funding-news-november-19-2026/)

Palo Alto Networks agreed to acquire Applied Compute, a post-training startup founded by former OpenAI researchers in 2025, in an all-stock deal valued at approximately $4.5 billion. The deal signals a major security vendor acquiring deep AI model expertise in-house.

**Why it matters:** Security companies acquiring AI model labs reflects the convergence of frontier model capabilities and enterprise security tooling — expect Palo Alto to integrate Applied Compute's post-training work directly into its AI-powered security products.
