## Research

### 3. MARO: Multi-Agent Reward Optimization for Better LLM Reasoning
**Source:** [VoltAgent awesome-ai-agent-papers](https://github.com/VoltAgent/awesome-ai-agent-papers)

A new paper proposes *Multi-Agent Reward Optimization (MARO)*, which decomposes outcomes from simulated multi-agent social interactions into per-behavior learning signals to improve LLM reasoning. Rather than training on end-to-end task success, MARO rewards individual agent behaviors in a social simulation context, surfacing richer training signal. This matters because standard RL for LLMs often collapses nuanced reasoning into blunt scalar rewards — MARO's social decomposition approach could yield models that generalize better across multi-step agent workflows.

### 4. HMARS: Hierarchical Multi-Agent Memory for Long-Context Reasoning
**Source:** [arXiv:2606.28349](https://arxiv.org/pdf/2606.28349)

*HMARS (Hierarchical Multi-Agent Memory System)* proposes a tiered memory architecture across a hierarchy of agents to tackle long-context reasoning — a persistent gap in current LLMs despite ever-growing context windows. Worker agents process segments and hand structured summaries upward through management layers, enabling queries that span hundreds of thousands of tokens without the hallucination accumulation that plagues flat long-context approaches. Increasingly relevant as production agents need to operate over session histories and large codebases.

### 5. RL for Multi-Agent Orchestration via Traces
**Source:** [arXiv:2605.02801](https://arxiv.org/pdf/2605.02801)

*Reinforcement Learning for LLM-based Multi-Agent Systems through Orchestration Traces* uses logged orchestration traces — the sequence of tool calls, handoffs, and decisions across a multi-agent run — as training data to fine-tune LLMs to become better orchestrators. This "learn from runs" approach could shorten the feedback loop for improving agent pipelines without requiring curated human demonstrations, and is gaining attention in the agent engineering community this week.
