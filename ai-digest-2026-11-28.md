## Research

### 4. Microsoft: State-Linked Groups Now Weaponizing ARTEX AI Framework Against Financial Sector
**Sources:** [Microsoft Storm-3358 / ARTEX report via CryptoBriefing](https://cryptobriefing.com/microsoft-storm-0940-artex-ai-attacks/) · [LetsDataScience](https://letsdatascience.com/news/microsoft-reports-storm-3358-using-artex-against-financial-s-549e54ae)

Microsoft Threat Intelligence published new reporting that Storm-3358, a Cambodia-based financially motivated group, has begun targeting financial-sector organizations using **ARTEX** — an open-source penetration-testing framework that uses LLMs to automate offensive security workflows. A separate report documented ARTEX being used to scan GitHub for exposed API keys and AI credentials, with one documented case going from GitHub scan to Azure Key Vault exfiltration in under five minutes. The reports follow October findings about the China-state-aligned Storm-0940 using ARTEX to compromise 2,250+ environments.

### 5. arXiv: Tokenisation Is APX-Hard (Complexity Proof)
**Source:** [ArXiv AI Research Digest 2026-11-27 (GitHub)](https://github.com/datnguyenquy94/news-radar/issues/1217)

A new paper ("Tokenisation is not in APX", Kastreva et al.) proves that finding an optimal tokenizer is APX-hard — meaning no polynomial-time algorithm can guarantee a constant-factor approximation unless P=NP. This has practical implications for LLM training efficiency and vocabulary design, confirming that tokenization optimization problems are fundamentally intractable at scale.

### 6. arXiv: AI Safety Monitor Evaluation Has a Systematic Blind Spot
**Source:** [ArXiv AI Research Digest 2026-11-27 (GitHub)](https://github.com/datnguyenquy94/news-radar/issues/1217)

A new paper identifies that using attack policies as proxies for dangerous behavior in AI monitor evaluations produces misleadingly low false-negative rates — a systematic flaw in a common safety-testing methodology. The finding is significant for labs using red-teaming outputs to validate monitors, suggesting current safety benchmarks may overstate reliability.
