## New Agent Tool

### 3. AWS Bedrock AgentCore Web Search — Generally Available
**Source:** [Agentic AI News](https://agentic.ai/news)

AWS pushed Web Search on Amazon Bedrock AgentCore to general availability on August 21. The managed server-side tool gives agents native web retrieval without requiring custom integrations or third-party APIs.

**Why it matters:** Pulling web search into a managed cloud service removes a common integration burden for enterprise agent builders and signals AWS deepening its vertical stack for agentic workloads.

## Research

### 6. "Markets, Not Planners: Decentralized Orchestration of LLM Agents with Private Information"
**Source:** [arXiv cs.MA](https://arxiv.org/list/cs.MA/recent) — Xiao Liu, Haoyang Li et al.

The paper proposes a market-based mechanism for coordinating multi-agent systems where agents hold private information, bypassing a central orchestrator. Submitted to arXiv on August 25–26.

**Why it matters:** Centralized orchestrators are a single point of failure and information bottleneck in large agent networks; market-based coordination could unlock more robust and scalable multi-agent architectures.

---

### 7. "CrystalMem: Elastic Memory for Self-Evolving LLM Agents via Knowledge Crystallization"
**Source:** [arXiv cs.AI August 2026](https://arxiv.org/list/cs.AI/current)

CrystalMem proposes an elastic memory system where agents distill ("crystallize") experience into compact, reusable knowledge structures rather than accumulating raw context. The system allows agents to self-improve across tasks without growing memory unboundedly.

**Why it matters:** Memory management is one of the hardest open problems in long-running agents; CrystalMem's crystallization approach offers a principled alternative to naive context accumulation or retrieval-augmented generation.

---

### 8. "Test-Time Collaborative Classification over Multi-Agent Networks" — arXiv
**Source:** [arXiv cs.MA](https://arxiv.org/list/cs.MA/recent) — Ping Hu, Mert Kayaalp, Ali H. Sayed

This paper studies how a network of agents can collaboratively classify at inference time by aggregating local beliefs without a shared training objective. Released August 25–26.

**Why it matters:** Collaborative inference without shared training points toward federated or privacy-preserving agent deployments where data cannot be centralized.
