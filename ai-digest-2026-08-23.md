## 4. DeepSeek Harness Open-Sourced Under MIT — "Everything Is a Plugin" · New Agent Tool

**Sources:** [The New Stack](https://thenewstack.io/deepseek-harness-open-source-plugins/) · [InfoQ](https://www.infoq.com/news/2026/08/deep-seek-harness/) · [Open Source For You](https://www.opensourceforu.com/2026/08/deepseek-open-sources-mit-licensed-harness-for-ai-coding-agents/) · [Flowtivity](https://flowtivity.ai/blog/deepseek-harness-open-source-agent-explained/)

On August 13, DeepSeek open-sourced **DeepSeek Harness** (CLI: `dsh`) under the MIT license. The framework turns DeepSeek's V4-series models into autonomous multi-step coding agents. Its defining design principle is that models, tools, skills, sessions, sandboxes, file systems, agent loops, and UI surfaces are all independently swappable plugins, built atop the **Cordis** meta-framework, which supports hot-swapping components without restarting the agent. The repo passed 95,000 GitHub stars within roughly two days — one of the fastest adoption curves ever recorded for a developer tool.

**Why it matters:** An MIT-licensed, fully modular agent harness from one of the most active open-source AI labs removes a key barrier for teams wanting customisable autonomous coding agents without vendor lock-in, and directly challenges proprietary runtimes from Microsoft (MAF) and Anthropic (Claude Agent SDK).
