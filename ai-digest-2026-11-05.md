## New Agent Tool

### 1. DeepSeek Open-Sources Super-Agent Autonomous Coding Agent
**Source:** [The Next Web](https://thenextweb.com/news/deepseek-super-agent-open-source-coding-agent) · [Digital Trends](https://www.digitaltrends.com/computing/deepseek-wants-to-steal-claude-code-and-codexs-lunch-with-an-ai-agent-that-does-not-wait-around/)

DeepSeek's Harness team released Super-Agent, an MIT-licensed open-source coding agent that monitors developer group chats (GitHub, Feishu) and proactively proposes code fixes without being summoned. Its architecture splits into a Router layer and parallel Worker sessions; it reached 4,000 GitHub stars within a day of release.

**Why it matters:** Unlike existing coding agents that react to explicit requests, Super-Agent's proactive, chat-aware design lowers the activation barrier for AI-assisted development. Its open-source MIT license makes it immediately adoptable and positions it as a direct rival to Anthropic's Claude Code and OpenAI's Codex.

### 2. Microsoft Agent Framework v2.65.0 Released
**Source:** [Kanerika — AI Agent Frameworks 2026](https://kanerika.com/blogs/ai-agent-frameworks/) · [Shakudo — Top 9 Agent Frameworks](https://www.shakudo.io/blog/top-9-ai-agent-frameworks)

Microsoft Agent Framework shipped version 2.65.0 on November 3, 2026. Microsoft has officially archived the AutoGen repository and is redirecting all users to this successor. The framework is now the top enterprise-recommended multi-agent coordination layer in the Microsoft ecosystem.

**Why it matters:** AutoGen's deprecation marks a significant consolidation. Teams already using AutoGen need to migrate; new entrants have a clearer path forward without the ambiguity of two overlapping Microsoft multi-agent projects.

### 3. Databricks Genie Agent Gains Unstructured File Analysis
**Source:** [Databricks AI/BI Release Notes 2026](https://docs.databricks.com/aws/en/ai-bi/release-notes/2026)

Databricks' Genie Agent (public preview, November 2, 2026) can now analyze unstructured files stored in Unity Catalog volumes — including PDFs, slide decks, and images — in addition to structured table data.

**Why it matters:** Closing the gap between structured analytics and unstructured content means data analysts can build fully agentic pipelines over their entire corpus without leaving the Databricks platform or wrangling separate ingestion steps.

## New Framework

### 4. Hugging Face smolagents v1.26.0
**Source:** [Shakudo — Top 9 Agent Frameworks](https://www.shakudo.io/blog/top-9-ai-agent-frameworks)

Hugging Face's Transformers Agents framework has been renamed to **smolagents** and reached v1.26.0. The rebranding reflects a philosophy of lightweight, composable agent design that keeps the dependency footprint small.

**Why it matters:** Hugging Face's ecosystem reach means smolagents is likely to become the go-to lightweight alternative to heavier orchestration frameworks like LangGraph or CrewAI for researchers and hobbyists.

### 8. China Blocks SoftBank's $5.4B ABB Robotics Acquisition
**Source:** [AI Weekly — Funding News Nov 5](https://aiweekly.co/ai-news-today/funding-ai-news)

## Research

### 9. FrontierPhysics: Benchmarking Agents on End-to-End Physics Research
**Source:** [ArXiv AI Research Digest 2026-11-05](https://github.com/datnguyenquy94/news-radar/issues/990) · [arXiv cs.AI November 2026](https://arxiv.org/list/cs.AI/current)

A new benchmark, FrontierPhysics, evaluates autonomous agents on full-cycle physics research tasks — from literature review through hypothesis generation to experimental design. Papers on Agentic Context Management (arXiv:2611.00518) and Sparse Autoencoder attribution (arXiv:2611.00606) also appeared in the November 5 arXiv batch.

**Why it matters:** Moving evaluation beyond narrow QA or coding tasks toward open-ended scientific research is a key step in understanding where current agents fail and what capability gaps remain before AI can meaningfully accelerate scientific discovery.
