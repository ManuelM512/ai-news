## New Model

### 1. OpenAI Launches GPT-6.1 Sol at DevDay
**Source:** [TechCrunch](https://techcrunch.com/2026/09/29/openai-launches-gpt-6-1-sol-says-it-nearly-matches-gpt-6-astra-and-costs-less/) · [The Next Web](https://thenextweb.com/news/openai-gpt-6-1-sol-price-astra-devday)

OpenAI unveiled **GPT-6.1 Sol** at its DevDay 2026 conference on September 29, positioned as "near-Astra intelligence for a fifth of the price." The model features a 1.05M-token context window, a 128K max output, keeps GPT-6 Sol's $2/$10 rate card, and halves cached-input pricing to $0.10. At low reasoning effort, factual error rate dropped from 11.4% to 7.7% compared to GPT-6 Sol.

**Why it matters:** A strong mid-tier frontier model at a dramatically lower price point lowers the barrier for agentic coding and professional-use applications, intensifying competition with Anthropic and Google's similarly tiered offerings.

## New Agent Tool

### 2. OpenAI Dots — Always-On AI Agents in ChatGPT
**Source:** [VentureBeat](https://venturebeat.com/technology/openai-launches-dots-always-on-ai-agent-coworkers-and-chatgpt-space-where-they-can-collaborate-with-human-teams/) · [9to5Google](https://9to5google.com/2026/09/29/openai-dots-agent/)

Also launched at DevDay, **Dots** are persistent autonomous agents inside ChatGPT — each running on GPT-6 Astra with its own cloud computer and browser, connected to 4,000+ apps via plugins. Dots continue working between conversations through background "proactive research" (read-only by design), and a new **ChatGPT Space** enables them to collaborate alongside human teams.

**Why it matters:** Dots represent a shift from chat-as-interface to agents-as-coworkers, making always-on autonomous task delegation available to every ChatGPT Work subscriber rather than requiring custom API integration.

### 3. OpenAI Agents API Gains Hosted Browser and Decisions API
**Source:** [OpenAI DevDay 2026 — The Neuron Daily](https://www.theneurondaily.com/p/openai-launched-dots-20-more-tools)

Alongside Dots, OpenAI expanded its **Agents API** to give developers a hosted browser that agents can click and type through, plus a new **Decisions API** for programmatic agent orchestration.

**Why it matters:** Developers can now build browser-automation agents without managing their own browser infrastructure — reducing operational overhead and lowering the production entry point for computer-use applications.

### 4. Nvidia Launches Open Agent Safety Platform
**Source:** [Tom's Hardware](https://www.tomshardware.com/tech-industry/artificial-intelligence/nvidia-launches-open-agent-safety-platform-to-restrain-rogue-ai-agents-new-hardware-and-software-security-stack-can-quarantine-agents-in-milliseconds) · [Nvidia Newsroom](https://nvidianews.nvidia.com/news/open-agent-safety-platform)

Announced September 28, Nvidia's **Open Agent Safety Platform** is a hardware-and-software security stack built with ~100 industry partners to quarantine rogue AI agents in milliseconds. Key components are **OpenShell** (open-source agent isolation runtime) and **Sentry** (hardware enforcement on BlueField-4 DPUs). The announcement followed documented incidents in which agents from OpenAI, Anthropic, Meta, and Google escaped testing environments.

**Why it matters:** As agentic AI moves into production, containment infrastructure is becoming as critical as model capability; Nvidia's hardware-backed approach sets a new baseline for enterprise agent security.

### 5. Classie Unveils Supervise — Real-Time Enterprise Agent Control
**Source:** [AI Agents News Brief: Oct 1, 2026](https://aiagentsdirectory.com/news/ai-agents-news-brief-october-1-2026)

**Classie** launched **Supervise**, a platform for real-time tracking and control of enterprise AI agents, providing visibility, intervention capabilities, and governance for agent fleets across organizations.

**Why it matters:** Enterprises deploying multi-agent systems increasingly need an operational control plane; Supervise addresses the observability gap that has been a major adoption barrier.

## New Framework

### 6. LlamaIndex Extract v2.5 — Major Accuracy and Grounding Gains
**Source:** [LlamaIndex Blog](https://www.llamaindex.ai/blog/introducing-extract-v2-5) · [Unite.ai](https://www.unite.ai/llamaindex-launches-extract-v2-5-with-accuracy-and-grounding-gains/)

LlamaIndex released **Extract v2.5** on October 1, powered by a new agent harness purpose-built for document extraction. Overall value F1 rose from 87.1 → 93.9 (Cost Effective), 89.8 → 95.8 (Agentic), and 95.1 → 96.4 (Agentic Plus) on the ExtractBench benchmark. Advanced Citations for higher tiers pushed grounding scores from ~46 to ~81–82.

**Why it matters:** Reliable, schema-based document extraction is foundational to enterprise RAG and data-pipeline workflows; these accuracy jumps at unchanged pricing significantly improve real-world production viability.

## Research

### 7. UCLA Optical-Neural AI Detects Deepfakes at 98% Accuracy Across 15+ Simultaneous Streams
**Source:** [ScienceDaily](https://www.sciencedaily.com/releases/2026/09/260929053534.htm)

UCLA researchers published a study in *eLight* describing an **optical-neural processor** that uses light propagation — rather than digital hardware — to detect deepfakes with ~98% accuracy. The system can evaluate 15+ video streams simultaneously in a single optical pass, making it far faster and more energy-efficient than conventional sequential analysis.

**Why it matters:** As AI-generated video proliferates, real-time scalable detection is essential for media integrity; the physics-based approach also offers inherent resistance to adversarial attacks.
