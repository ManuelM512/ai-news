### 6. Funes — Cross-Agent Memory Layer (Hugging Face)
**Source:** [GitHub](https://github.com/huggingface/funes) · [Hugging Face Blog](https://huggingface.co/blog/funes)

Hugging Face released Funes, an open-source local memory layer for AI coding agents. It indexes past sessions from Claude Code, Codex, and other agents into a single Lance vector+BM25 store, returning original text (not summaries) with full provenance — agent, timestamp, session, turn.

**Why it matters:** Cross-agent persistent memory has been a major gap in the agentic tooling stack. Funes solves the cold-start problem for long-running projects, and its local-first design keeps session data off external servers — critical for enterprise and regulated environments.
