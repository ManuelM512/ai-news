## New Model

### 1. Meta Launches Muse Wonder 1.0 — Its First Frontier-Class AI Model
**Source:** [VentureBeat](https://venturebeat.com/technology/metas-new-muse-wonder-and-muse-wonder-full-models-achieve-frontier-performance-but-only-the-weaker-one-is-available-via-api) · [Bloomberg](https://www.bloomberg.com/news/articles/2026-10-12/meta-says-new-muse-model-reaches-ai-frontier-after-14-month-push) · [AI Weekly](https://aiweekly.co/alerts/meta-releases-muse-wonder-its-first-frontier-class-ai-model)

Meta's Meta Superintelligence Labs (led by former Scale AI CEO Alexandr Wang) released Muse Wonder 1.0 on October 12, a multimodal model that accepts text, images, audio, and video as input, with a ~1M token context window and strong performance in coding, legal, and financial tasks. A more capable "Muse Wonder Full" variant was also released but is gated to paid subscribers of Meta's Muse Code assistant; the standard model is available via API at $4/M input tokens and $20/M output tokens.

**Why it matters:** This is Meta's most credible claim yet to frontier-class performance, scoring 52 on the Artificial Analysis Intelligence Index (vs. Claude Opus 5.5 at 58). It's designed specifically for multi-application agents with error recovery — signaling Meta's serious push into the enterprise AI market.

## New Agent Tool

### 2. Oracle Fusion Claw: Agent Orchestration Inside ERP
**Source:** [AI Agent Store](https://aiagentstore.ai/ai-agent-news/today)

Oracle launched "Fusion Claw," an agent orchestration layer embedded directly in its Fusion Applications ERP platform. It lets enterprises define standard operating procedures, risk thresholds, and decision rights natively inside Fusion, allowing AI agents to take actions scoped within the ERP's governance model.

**Why it matters:** Enterprise-native agent orchestration that respects existing compliance and audit controls is a major blocker for AI adoption in regulated industries. Fusion Claw attempts to solve this without requiring a separate orchestration platform.

## Research

### 3. Anthropic "Preserved Thinking" Safeguards Cut Distillation by 90–99%
**Source:** [AI Weekly](https://aiweekly.co/ai-news-today)

Anthropic published results showing new "preserved thinking" safeguards in Claude Fable 5.1 and Opus 5.5 reduce the ability of third parties to distill the models' reasoning chains by 90–99%. The same report notes that Anthropic's Frontier Red Team assesses that small open-weight models may be only months away from autonomously replicating themselves on commercial IoT hardware.

**Why it matters:** Model distillation by downstream actors is one of the leading ways frontier capability proliferates without safety alignment. This is the first published measure of how much a deployed safeguard actually limits it.

### 4. Long-Horizon Language Agent Memory (arXiv:2610.00010)
**Source:** [arXiv cs.AI October 2026](https://arxiv.org/list/cs.AI/current)

A new paper studies how language agents maintain coherent memory across very long task horizons, evaluating several architectures on benchmarks requiring hundreds of action steps. The work identifies failure modes where agents lose track of early-task context and proposes a sparse-retrieval memory module to address them.

**Why it matters:** Long-horizon reliability is one of the core unsolved problems for practical autonomous agents. This paper offers both a diagnosis and a concrete architectural improvement.

### 5. RSI-Anything: World Models + Agent Feedback for Recursive Self-Improvement
**Source:** [alphaXiv feed, early October 2026](https://www.alphaxiv.org/)

A new preprint describes RSI-Anything, a framework that pairs world models with multi-agent self-supervision to enable iterative self-improvement loops. The system allows an agent to generate training data for itself by running simulations and using disagreement between sub-agents as a training signal.

**Why it matters:** Recursive self-improvement remains a key capability milestone and safety concern. This paper presents an empirical approach rather than a theoretical one and demonstrates measurable performance gains on code generation tasks.

### 7. arXiv Rate-Limiting Policy Takes Effect — Caps Submissions per Author
**Source:** [arXiv blog](https://blog.arxiv.org/2026/10/01/updated-rate-limit-policy/)

Starting October 1, 2026, arXiv is enforcing a rate-limiting policy that caps each submitter at two new paper submissions per month across all categories, including rejected ones. The policy is framed as a temporary stopgap while arXiv develops longer-term guidelines for AI-assisted submissions.

**Why it matters:** The rapid growth of AI-generated or AI-assisted research submissions has strained arXiv's review capacity. This policy directly affects researchers using AI tools for paper writing and may slow the pace of preprint releases across ML and AI.

### 8. Manus Raises $500M Led by Tencent and Sequoia China
**Source:** [AI Funding Tracker](https://superpowerdaily.com/signals/funding) · [Scouts by Yutori](https://scouts.yutori.com/68f22e10-d5fe-4e94-b1c8-9c6218cfdb2c)

General-purpose AI agent startup Manus closed a $500M round (reported October 7) led by Tencent, HSG, and Sequoia China, following its separation from Meta. The round values the company at several billion dollars and comes as Manus positions itself as a standalone autonomous agent platform.

**Why it matters:** With Meta's Muse Wonder now targeting the same agent use cases, Manus faces direct competition from its former partner. The scale of this round gives it runway to differentiate but the competitive pressure is immediate.
