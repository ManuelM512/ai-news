## New Model

### 1. Moonshot AI Releases Kimi K3.1 Pro Open Weights
**Source:** [LetsDataScience](https://letsdatascience.com/news/moonshot-releases-kimi-k31-pro-api-open-weights-due-nov-4-786e160c) · [Vals.ai](https://www.vals.ai/models/kimi_kimi-k3.1-pro)

Moonshot AI's Kimi K3.1 Pro open weights are scheduled for public release today (Nov 4), following the API launch on October 23. The model is a 2.8T-parameter MoE with 104B active parameters, a 1-million-token context window, and pricing of $2/$10 per million input/output tokens. Benchmarks put it at #8 on the Vals Index (62.52%), currently the leading open-weight model and within a few points of the best proprietary frontier models.

**Why it matters:** A near-frontier open-weight model with a million-token context is a significant resource for self-hosting teams; Moonshot also stripped cyber-related data from the open-weight version's training, flagging deliberate safety choices for community releases.

## New Agent Tool

### 4. SAP Launches Managed Joule Studio with Claude Code and Cursor Support
**Source:** [The New Stack](https://thenewstack.io/sap-joule-studio-managed-agents/) · [Pulse.bot](https://www.pulse.bot/enterprise/news/sap-launches-managed-joule-studio-with-cursor-and-claude-code-support-3127bc11-8340-4643-9564-149bd84ea21a/)

SAP's Managed Joule Studio now supports Claude Code, Cursor, and VS Code as first-class coding tools, alongside agent frameworks LangGraph, CrewAI, AutoGen, and LlamaIndex. Agents get persistent long-term memory backed by SAP HANA Cloud, and each agent receives a unique identity from SAP Cloud Identity Services. The SAP AI Agent Hub provides IT teams with centralized governance over agents, LLMs, and MCP servers.

**Why it matters:** Bringing Claude Code and industry-standard agent frameworks into SAP's ecosystem lowers the barrier to deploying enterprise AI agents across SAP's vast installed base of ERP and business-process customers.

## Research

### 7. OpenCUA: Open-Source Computer-Use Agents Rival Proprietary Models
**Source:** [arXiv / NeurIPS 2025](https://arxiv.org/abs/2508.09123) · [VentureBeat](https://venturebeat.com/ai/opencuas-open-source-computer-use-agents-rival-proprietary-models-from-openai-and-anthropic)

OpenCUA, presented at NeurIPS 2025, is an open-source computer-use agent framework. Its 72B model achieves a 45.0% average success rate on OSWorld-Verified — competitive with OpenAI's and Anthropic's proprietary computer-use agents.

**Why it matters:** Closing the gap to proprietary GUI agents with open weights democratises computer-use automation and enables security-sensitive enterprises to self-host screen-interaction agents.

---

### 8. LLMs Can Directly Edit Their Own Weights to Fix Failures
**Source:** [AlphaXiv trending — November 2026](https://www.alphaxiv.org/)

A trending paper shows that LLMs can inspect and surgically edit their own neural-network weights to correct specific failure modes, without full fine-tuning. The technique targets individual facts or behaviours and leaves surrounding capabilities intact.

**Why it matters:** If the approach generalises robustly, it could replace costly fine-tuning runs for narrow capability patches and open a path toward self-correcting models in production.

---

### 9. Democratizing Robot-Use Agents with Open Models
**Source:** [Hugging Face Trending Papers](https://huggingface.co/papers/trending)

A new paper introduces a unified harness for deploying robot-use agents with open models, lowering the compute and licensing barrier to robotic AI. It ranked in Hugging Face's top trending papers for the week.

**Why it matters:** Open, standardised robot-agent interfaces could accelerate physical AI adoption the same way open LLM weights did for language tasks.
