## New Model

### 1. Kimi K3 Open Weights Go Live — Largest Open-Weight Release in History
**Source:** [buildfastwithai.com](https://www.buildfastwithai.com/blogs/ai-news-today-july-27-2026) | [llm-stats.com](https://llm-stats.com/llm-updates)

Moonshot AI's Kimi K3 full weights went live at 00:00 UTC today, making the 2.8-trillion-parameter sparse Mixture-of-Experts model free to download. The full weight package is roughly 1.4 terabytes using MXFP4 quantization, with a 1M-token context window and native multimodal (text, image, video) input. Together with DeepSeek V4's stable release on July 24, this marks the largest concentration of open-weight frontier releases the industry has seen in a single week.

**Why it matters:** At 2.8T parameters, Kimi K3 is the largest open-weight model ever released — a scale previously only accessible via closed APIs. Self-hosted deployments of near-frontier capability just became a real option for well-resourced teams, intensifying competition with closed labs.

### 3. NVIDIA Cosmos 3 Edge — 4B Physical AI Model Runs on a Single RTX GPU
**Source:** [NVIDIA Blog](https://blogs.nvidia.com/blog/siggraph-news-2026/) | [TechTimes](https://www.techtimes.com/articles/321401/20260723/nvidia-siggraph-cosmos-3-edge-brings-physical-ai-pipeline-single-gpu.htm)

Announced at SIGGRAPH 2026 and released on Hugging Face with full weights, Cosmos 3 Edge is a 4-billion-parameter open world foundation model designed for real-time edge deployment. It accepts text, images, video, audio, and robot actions; outputs robot actions at 15 Hz on a Jetson Thor; and ranks first on the VANTAGE-Bench leaderboard for vision analytics in its parameter class. The autonomous-vehicle simulator task that previously required 64 GB300 GPUs now runs on a single NVIDIA RTX PRO 6000 workstation card.

**Why it matters:** Physical AI — robotics and autonomous systems — has faced a compute accessibility barrier. Cosmos 3 Edge collapses that barrier to a single prosumer GPU, opening the field to a much broader set of hardware budgets.

## New Framework

### 5. Miles by RadixArk — PyTorch-Native Framework for Large-Scale LLM RL Post-Training
**Source:** [PyTorch Blog](https://pytorch.org/blog/miles-a-pytorch-native-stack-for-large-scale-llm-rl-post-training/) | [aiinsiders.net](https://aiinsiders.net/article/radixark-open-sources-miles-a-pytorch-rl-stack-for-frontier)

RadixArk open-sourced Miles, a framework for large-scale LLM reinforcement learning post-training built around a small decorator-based API: developers annotate two functions (`@rollout` and `@update`) and Miles handles distribution, data streaming, and synchronization. Under the hood it composes SGLang for rollout, NVIDIA Megatron-LM for training, and Ray orchestration, with unified low-precision recipes, MoE-aware alignment, and NCCL/RDMA weight synchronization built in. The announcement was featured on the PyTorch Foundation blog.

**Why it matters:** RL post-training (RLHF, RLVR) at frontier scale is a distributed systems problem that most research teams can't easily reproduce. Miles makes that infrastructure composable and open-source, potentially widening access to the same training methods labs use to produce their most capable models.

## Research

### 6. ResearchClawBench — New Benchmark Tests If AI Agents Can Do Autonomous Science
**Source:** [agentic.ai](https://agentic.ai/news) | [dev.to](https://dev.to/necatiozmen/awesome-ai-agent-papers-2026-2ili)

ResearchClawBench is a new benchmark from Zhejiang University's Qiushi Engine that tests whether AI agents can independently plan and execute research workflows — literature review, experiment design, analysis — producing outputs scored against human-written reference papers. As of this week, Qiushi Engine holds the top spot on the leaderboard.

**Why it matters:** Most agent benchmarks test tool use and task completion on well-defined problems. ResearchClawBench raises the stakes to open-ended scientific reasoning, providing a target metric for the "autonomous scientist" use case labs increasingly claim to be working toward.
