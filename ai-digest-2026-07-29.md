# AI News Digest — 2026-07-29

## New Agent Tool

### MCP 2026-07-28 Specification — Final Release
**Source:** [Model Context Protocol Blog](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/)

The Model Context Protocol (MCP) published its largest revision since launch on July 28, going fully stateless at the protocol layer. A remote MCP server no longer needs sticky sessions or shared session stores — it can run behind a plain round-robin load balancer, route traffic on an `Mcp-Method` header, and let clients cache tool-list responses with a configurable `ttlMs`. The update also adds server-rendered UIs via MCP Apps, long-running work via a Tasks extension, and OAuth/OIDC-aligned authorization.

**Why it matters:** Stateless MCP dramatically lowers the infrastructure bar for production deployments, removing a key operational burden that had slowed enterprise adoption of agent toolchains.

## Research

### ICML 2026: Selective Activation Sparsity Enables 3× Size Efficiency
**Source:** [AI Research Breakthroughs in July 2026 — Skycrumbs Blog](https://skycrumbs.com/blog/ai-research-july-2026)

A paper presented at ICML 2026 introduced "selective activation sparsity," a training method that teaches models to activate only the most relevant parameters for each task. Models trained with this approach perform comparably to models three times their size on reasoning benchmarks, without any inference-time changes.

**Why it matters:** Parameter-efficient training methods that preserve reasoning quality at a fraction of the compute could reshape how smaller labs and edge deployments approach model deployment costs.

## Other — Security

### Hugging Face Publishes Phase-by-Phase Reconstruction of OpenAI Agent Intrusion
**Source:** [AI News Briefs — Radical Data Science](https://radicaldatascience.wordpress.com/2026/07/28/ai-news-briefs-bulletin-board-for-july-2026/)

Hugging Face's security team released a detailed post-mortem on the July 9–13 breach of OpenAI's agent infrastructure, reconstructing roughly 17,600 attacker actions across ~6,280 operations. The report traces the intrusion path phase-by-phase, from initial access to lateral movement across agent workloads.

**Why it matters:** This is one of the most detailed public analyses of an AI infrastructure compromise to date, offering concrete indicators of compromise and a playbook for defenders building agent systems.

## Other — Industry Initiative

### Nvidia Launches Open Secure AI Alliance with 44 Founding Partners
**Source:** [NVIDIA Blog](https://blogs.nvidia.com/blog/open-secure-ai-alliance/) · [The Hacker News](https://thehackernews.com/2026/07/nvidia-forms-37-member-open-secure-ai.html)

Nvidia launched the Open Secure AI Alliance on July 27, bringing together 44 founding partners — including Microsoft, IBM, Red Hat, Hugging Face, Cloudflare, CrowdStrike, Palo Alto Networks, Databricks, and the Linux Foundation — to build and share open-source cybersecurity tooling for AI. Nvidia contributed its NOOA agent harness research framework; SpaceXAI open-sourced its Grok Build coding agent.

**Why it matters:** A large cross-industry security coalition for AI is a meaningful shift from ad-hoc vendor responses; open-sourced defensive tools like NOOA could set shared baselines for agent hardening.

## Other — Policy

### White House Drafts 30-Day National Security Review Window for Frontier Models
**Source:** [Updated Bulletins — OpenAI, Google, Anthropic July 2026](https://updatedbulletins.com/ai-news-july-2026-openai-google-anthropic-updates/)

The White House is finalizing a voluntary framework with OpenAI, Anthropic, and Google that would give federal agencies up to 30 days to review the national security implications of a new frontier model before public deployment. The framework is still in negotiation and has not been signed.

**Why it matters:** A pre-deployment government review window — even voluntary — would represent the most concrete U.S. regulatory checkpoint on frontier model releases to date, with potential precedent-setting effects on the broader industry.
