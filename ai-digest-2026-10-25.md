## New Agent Tool

### 5. Agentic AI Foundation Adds Four New Projects, Reaches 10 Total
**Source:** [Linux Foundation Press Release](https://www.linuxfoundation.org/press/agentic-ai-foundation-announces-four-new-projects-agent-skills-open-responses-openenv-and-opensandbox) · [Unite.AI](https://www.unite.ai/agentic-ai-foundation-adds-four-projects-to-reach-10-in-first-year/)

Timed to AGNTCon + MCPCon North America (October 22–23, San Jose), the Agentic AI Foundation (AAIF) announced four new hosted projects: **Agent Skills** (contributed by Anthropic), **Open Responses** (contributed by OpenAI), **OpenEnv** (contributed by Hugging Face), and **OpenSandbox** (contributed by Alibaba). The additions bring AAIF to 10 hosted projects in its first year. This cross-lab collaboration on open agent infrastructure is a strong signal that the industry is converging on shared interoperability primitives.

### 6. Notion Rolls Out Sixth-Generation Agent Harness with 24+ Hour Task Runs
**Source:** [AI Agent Store — Week of October 22, 2026](https://aiagentstore.ai/ai-agent-news/this-week)

Notion released a sixth-generation agent harness capable of sustaining single-agent tasks for more than 24 hours—up from its previous five-minute limit. This dramatically expands the scope of autonomous workflows that can run inside Notion, from short document edits to day-long research and writing projects.

### 7. Google Announces Agent Runtime — Per-Second Billing for Agent Compute
**Source:** [GCP April 2026 Monthly Update](https://www.usage.ai/blogs/gcp/monthly-updates/gcp-april-2026/)

Google's Gemini Enterprise Agent Platform consolidates Vertex AI agent tools, Agentspace, and ADK into a unified surface, with Agent Runtime serving as the compute layer. Agent Runtime offers sub-second cold starts and per-vCPU-second billing, so idle agents incur no cost. This infrastructure model, borrowing from serverless patterns, may set a pricing benchmark for agentic compute across the industry.

## Research

### 8. Google's Harness² Paper: Agents That Improve Their Own Execution Harnesses
**Source:** [Hugging Face Trending Papers](https://huggingface.co/papers/trending)

A Google paper published October 9 (and trending this week) proposes *Harness²*, a method letting agents iteratively improve the execution harnesses they run within—without requiring ground-truth verifiers. The approach is notable because it sidesteps the need for labeled feedback, a major bottleneck in agent self-improvement research.

### 10. Microsoft Reports China-State Actor Using AI Agent Framework to Target 2,250+ Tenants
**Source:** [AI Agent Store — Week of October 22, 2026](https://aiagentstore.ai/ai-agent-news/this-week)

Microsoft disclosed that a China-state-aligned threat actor used an AI agent framework to attempt sign-ins across more than 2,250 Microsoft tenants. The incident is one of the first publicly documented cases of adversarial use of agentic AI at enterprise scale, and will likely accelerate calls for guardrails on agent authentication and access delegation.
