## New Model

### 1. xAI Grok Voice Think Fast 2.0 Goes Live
**Source:** [x.ai](https://x.ai/news/grok-voice-think-fast-2) · [xAI Release Notes](https://releasebot.io/updates/xai) · [Digital Applied](https://www.digitalapplied.com/blog/grok-voice-think-fast-2-speech-to-speech-agents-2026)

On August 5, `grok-voice-latest` switched from Think Fast 1.0 to Think Fast 2.0 — xAI's next-generation speech-to-speech model. Time to first audio dropped from 1.25 seconds to 0.70 seconds, overall accuracy rose to 82.9% on Artificial Analysis' benchmark (beating GPT-Realtime-2.1 at 79.1% and Gemini 3.1 Flash at 69.5%), and noisy-environment transcription accuracy reportedly leads competitors by ~10×. Pricing moves from $0.05 to $0.08 per minute; users who want to stay on 1.0 must pin `grok-voice-think-fast-1.0` explicitly.

**Why it matters:** Think Fast 2.0 marks a measurable step forward in real-time speech AI, with better tool-use reliability alongside the speed and accuracy gains — positioning xAI's voice stack as a serious competitor for voice-agent applications.

## New Agent Tool

### 2. LLM 0.32 — Reasoning Traces, MCP Integration, and OpenAI Responses API
**Source:** [Simon Willison's Weblog](https://simonwillison.net/2026/Aug/4/new-release-of-llm/) · [Mastodon](https://fedi.simonwillison.net/@simon/117039969641535860)

Simon Willison released LLM 0.32 on August 4, calling it the most significant version since the project launched. Key additions: visible reasoning trace support, the OpenAI Responses API (enabling server-side provider tools and more structured outputs), a redesigned content-addressable SQLite log store for smarter query and deduplication, and a new `llm openai endpoint` command that runs a one-liner against any OpenAI-compatible endpoint. The Anthropic integration also now executes MCP calls in a single request/response round-trip.

**Why it matters:** LLM is one of the most widely used open-source CLI/Python tools for interacting with language models; this release brings first-class agentic primitives (reasoning visibility, tool calls, MCP) to the command line with minimal friction.

### 3. Microsoft Agent Framework Harness and Foundry Hosted Agents Reach General Availability
**Source:** [InfoQ](https://www.infoq.com/news/2026/08/agent-framework-harness-ga/) · [Microsoft Agent Framework Blog](https://devblogs.microsoft.com/agent-framework/the-microsoft-agent-framework-harness-is-now-released/) · [Foundry Blog](https://devblogs.microsoft.com/foundry/agent-service-build2026/)

The Microsoft Agent Framework Harness and Foundry Hosted Agents are now generally available. The Harness is the layer where model reasoning meets real execution — providing shell and filesystem access, human-in-the-loop approval flows, and context management across long-running sessions, running as a single binary from local dev through containers to hosted deployment. Foundry Hosted Agents let teams ship an agent as a container with built-in identity, auto-scaling, managed session state, observability, and versioning.

**Why it matters:** Microsoft has officially moved beyond the SDK stage — this is a supported production runtime that competes with managed agent platforms from AWS (AgentCore) and Google (Vertex AI Agents), and it ships with native connectors to both GitHub Copilot and the Claude Agent SDK.

### 4. Cequence Extends Agentic Zero Trust Across MCP, API, and LLM
**Source:** [Source Security](https://www.sourcesecurity.com/news/cequence-ai-gateway-enhancements-agentic-ai-co-1654677090-ga.1785492115.html) · [Security MEA](https://securitymea.com/2026/07/31/cequence-brings-agentic-zero-trust-across-mcp-api-and-llm/) · [VMBlog](https://vmblog.com/news/cequence-brings-agentic-zero-trust-across-mcp-api-and-llm-so-every-business-team-can-deploy-agents-without-losing-control/)

Cequence released four new AI Gateway capabilities: **AI Discovery** (surfaces every agent, AI provider, and MCP server already running across the enterprise), **API Registry**, **LLM Registry** (governs every call to and from a model), and **Skill Registry**. The updated Agent Personas feature binds an agent's job description directly to its model, tools, access rights, and guardrails — enforced automatically through policy. The company calls the combined approach "Agentic Zero Trust": nothing an agent touches is implicitly trusted, and every action is scoped to exactly what its job requires.

**Why it matters:** As enterprises deploy agents at scale, unmanaged MCP servers and unconstrained LLM calls have become a top security concern — this release provides a runtime enforcement layer that addresses identity, discovery, and governance without requiring teams to audit code manually.

## Research

### 5. Together AI: Batch-Aware MoE Routing Cuts Inference Latency 39%
**Source:** [Together AI Blog — ICML 2026](https://www.together.ai/blog/icml-2026) · [ICML 2026 Program](https://icml.cc/virtual/2026/events/oral)

Presented at ICML 2026, Together AI's research addresses a key problem in Mixture-of-Experts inference: batching collapses the model's designed sparsity. At batch size 16, a model where each token selects 8 experts ends up loading ~82 of them. Their batch-aware routing recovers sparsity at inference time through a two-phase process — the second phase lets tokens share experts already loaded by the batch — achieving 39% lower decode latency with a single tunable hyperparameter, while holding accuracy flat across AIME24, GPQA, LiveCodeBench, and MATH 500.

**Why it matters:** MoE models are increasingly the dominant architecture for frontier AI (DeepSeek V4, Qwen3.8-Max, GPT-5.6), and compute-efficient batched inference is the key to making them affordable at enterprise scale — this gives a practical path to reclaiming their theoretical efficiency in production.

### 6. Anaconda Acquires Enkrypt AI to Secure Enterprise AI Pipelines
**Source:** [Anaconda Blog](https://www.anaconda.com/blog/anaconda-acquires-enkrypt-ai) · [HPCwire](https://www.hpcwire.com/aiwire/2026/08/04/anaconda-acquires-enkrypt-ai-to-secure-the-trillion-token-enterprise/) · [AI Weekly](https://aiweekly.co/ai-news-today)

Announced August 4, Anaconda acquired AI-security startup Enkrypt AI for an undisclosed sum. Enkrypt brings pre-deployment red-teaming across 300+ attack categories, runtime guardrails, and compliance automation mapped to NIST AI RMF and the EU AI Act into the Anaconda Platform. In the two months prior to the acquisition, Enkrypt scanned 268,000 tools across 25,000 MCP servers and found 143,000 vulnerabilities affecting 73% of them.

**Why it matters:** MCP tooling has proliferated far faster than security practices have caught up; embedding automated red-teaming and runtime guardrails directly into a widely-used data-science platform gives a large installed base immediate access to AI security tooling without a separate product purchase.
