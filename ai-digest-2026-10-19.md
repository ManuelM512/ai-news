## New Model

### 1. Meta Releases Open Weights for Muse Spark
**Source:** [eWeek](https://www.eweek.com/news/meta-muse-spark-ai-coding/) · [ProPakistani](https://propakistani.pk/2026/09/03/meta-launches-muse-spark-1-3-with-faster-coding-and-smarter-agents/) · [SiliconAngle](https://siliconangle.com/?p=850737)

Meta released open weights for **Muse Spark Open** on October 15, derived from the proprietary Muse Spark 1.2. It is a 816B-parameter mixture-of-experts model with only ~42B parameters active per inference and a 1M-token context window. Meta calls it the most capable open-weight model from a US lab to date. It was designed for long-horizon coding tasks and agentic workflows and cleared Meta's Superintelligence Scaling Framework safety thresholds before release.

**Why it matters:** Open weights at this scale give self-hosted and research deployments access to a frontier-class coding and agent model without API costs or data-sharing constraints.

### 3. xAI Launches Grok Voice 3.0
**Source:** [DevX](https://www.devx.com/artificial-intelligence-ai/what-is-grok-voice-3-0-xai-speech-to-speech-model/) · [LLM Reference](https://www.llmreference.com/model/grok-voice-3.0) · [BenchLM](https://benchlm.ai/md/models/grok-voice-3-0.md)

xAI released **Grok Voice 3.0** on October 14 in its Voice Agent API at $0.08/min. The speech-to-speech model supports real-time turn-taking and interruption handling with sub-one-second latency. Sessions include audio/text, custom voices, function calls, web search, and MCP tool support. The `grok-voice-latest` alias was updated to point to this release; Grok Voice 2.0 is now deprecated.

**Why it matters:** Native MCP tool support in a voice model enables real-time agentic voice interactions — a key building block for phone-based AI agents and contact-center automation.

## New Agent Tool

### 5. American Express Launches Intent Intelligence Framework for AI Agent Payments
**Source:** [TechCrunch](https://techcrunch.com/2026/10/13/amex-introduces-a-framework-to-prevent-ai-agents-from-making-unauthorized-purchases/) · [The AI Insider](https://theaiinsider.tech/2026/10/13/american-express-introduces-intent-intelligence-framework-to-secure-ai-agent-purchases/)

American Express released the **Intent Intelligence Framework** on October 13 as part of its Agentic Commerce Experiences (ACE) Developer Toolkit. The framework verifies a customer's purchase intent before an AI agent completes a financial transaction, adding an authorization layer between autonomous agents and payment execution.

**Why it matters:** As AI agents are increasingly trusted to manage purchases, frameworks that enforce user intent at the payment layer are essential infrastructure for safe agentic commerce at scale.

## Other

### 6. AMA Releases Governance Framework for Clinical AI Agents
**Source:** [Healthcare Dive](https://www.healthcaredive.com/news/ama-releases-governance-framework-for-agentic-ai-in-healthcare/833120/)

The American Medical Association (AMA) published a governance framework on October 15 for AI agents operating in clinical settings. The framework is structured around four questions covering clinical function, performance evidence, permitted actions, and responsibility for outcomes.

**Why it matters:** Healthcare is one of the highest-stakes domains for AI agents; AMA's framework sets a professional standard that could influence regulatory requirements and liability structures for clinical AI deployments.
