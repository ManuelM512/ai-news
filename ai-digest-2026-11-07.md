## New Model

### 1. Tencent Hy4 — Full Release with Vision & Computer Use
**Source:** [unite.ai](https://www.unite.ai/?p=502323) · [tech-insider.org](https://tech-insider.org/tencent-hy4-open-source-770b-parameters-1m-token-context-2026/)

Tencent announced the full release of Hy4 on November 4, adding vision understanding and computer-use capabilities to what was previously an open-weight preview. The model is a 770B-parameter Mixture-of-Experts architecture (49B active) with a 1M-token context window, now available through hosted APIs and integrated into Tencent products. Model weights and a comprehensive system card are planned for a later release; a cost-efficient Hy4 Flash variant is also on the roadmap.

**Why it matters:** Hy4 brings another frontier-class open-weight model into competition with GPT-5 and Gemini Ultra tiers, with native computer-use capabilities and exceptionally long context, strengthening the case that Chinese labs are tracking frontier performance closely.

**Source:** [Bloomberg](https://bloomberg.com/news/articles/2026-11-06/openai-completes-11-billion-portion-of-funding-at-1-25-trillion-value) · [AI News Nov 6](https://usecarly.com/blog/ai-news-2026-11-06)

## Research

### 6. MEMENTO: Context Management for Long-Context Processing Agents
**Source:** [arXiv cs.CL — November 2026](https://arxiv.org/list/cs.CL/current)

A new paper introduces MEMENTO, a learned context management system that teaches agents when to retain, compress, or evict information across ultra-long sessions. The approach is evaluated on multi-step tasks where naive full-context approaches fail due to attention dilution at extreme lengths.

**Why it matters:** As production agents routinely face sessions exceeding 500K tokens, principled context management is becoming a first-class engineering problem; MEMENTO offers a trainable approach that could integrate into existing agent frameworks.

### 7. What Standard Evaluations Hide About Detectors of Hijacked LLM Agents
**Source:** [DailyArXiv Nov 3, 2026](https://github.com/bddk520/DailyArXiv/issues/427)

This paper shows that standard benchmark performance for prompt-injection detectors dramatically overstates real-world effectiveness, particularly against rare attack variants and previously-unseen tool schemas. Detectors trained on common attack patterns fail to generalize when agents operate with new tools or when attack styles shift.

**Why it matters:** With prompt injection ranked as a top risk for deployed agents, this work is a direct challenge to operators relying on off-the-shelf detection to secure production agent pipelines.

### 8. Coati: Host-Grounded Execution for Installable Mobile GUI Agents
**Source:** [arXiv cs.MA — November 2026](https://arxiv.org/list/cs.MA/current)

Coati proposes a framework for mobile GUI agents that grounds execution in the host OS's accessibility tree rather than raw screenshot pixels, enabling more reliable and verifiable action execution across installable mobile apps. The approach reportedly reduces error rates on complex multi-step mobile tasks versus vision-only baselines.

**Why it matters:** Mobile GUI agents are a rapidly growing category; grounding actions in structured OS representations rather than pixel-level screenshots is an important shift toward more robust, auditable automation.

### 9. Accept Changes, Reject Attacks: Robust Memory Management for LLM Agents
**Source:** [DailyArXiv Nov 3, 2026](https://github.com/bddk520/DailyArXiv/issues/427)

This paper presents a defense mechanism for long-term memory in LLM agents, specifically targeting adversarial memory poisoning attacks where malicious content embedded in past interactions corrupts future reasoning. The proposed scheme selectively validates memory writes against a lightweight integrity policy.

**Why it matters:** Persistent memory is essential for agentic systems operating across sessions, but it creates a novel attack surface; this work is an early systematic treatment of memory integrity as a security property.
