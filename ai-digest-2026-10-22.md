## New Model

### 1. MiniMax M3.1 Flash — Fast Multimodal Coding Model Goes Public
**Source:** [DataNorth](https://datanorth.ai/news/minimax-releases-m3-1-flash-preview) · [LLM Gateway](https://llmgateway.io/models/minimax-m3.1-flash)

MiniMax released M3.1 Flash on October 19, the production version of a September preview. It is a multimodal coding model with a 1,000,000-token context window, adjustable reasoning, and API pricing of $0.15/$0.60 per million input/output tokens (cache reads at $0.015/M). The company claims it costs one-third of M3 and runs at triple the speed; model weights are due October 23.

**Why it matters:** A long-context, cheap, fast coding model with open weights coming shortly puts competitive pressure on closed API-only offerings and gives self-hosting teams a capable alternative for agentic code-generation pipelines.

## New Agent Tool

### 2. Perplexity Open-Sources SPACE — Firecracker microVM Sandbox for Agents
**Source:** [RuntimeWire](https://runtimewire.com/article/perplexity-open-sources-space-agent-sandbox) · [Perplexity Hub](https://hub-prod.perplexity.ai/hub/blog/secure-sandboxes-for-agents) · [TechStrong](https://techstrong.ai/articles/perplexity-unveils-space-a-secure-sandbox-platform-for-ai-agents/)

Perplexity open-sourced SPACE (Apache 2.0) around October 15, the Firecracker-microVM sandbox that has been running every Computer agent session since July. Each task runs in an isolated Linux kernel; sandboxes are destroyed on completion, with rolling snapshots for pause/resume/branching. The Rust implementation exposes an E2B-compatible HTTP API and reports median sandbox creation latency of 60 ms (down from 185 ms), handling millions of creations per day.

**Why it matters:** Production-grade, open-source microVM sandboxing lowers the bar for teams building agent pipelines that need safe, isolated execution — without building their own infrastructure from scratch.

### 3. ServiceNow AI Passport — Cryptographically Signed Runtime Credentials for Agents
**Source:** [CDO Magazine](https://www.cdomagazine.tech/aiml/servicenow-unveils-ai-passport-to-enforce-what-ai-agents-can-do-while-they-run) · [CIO](https://www.cio.com/article/4235863/servicenow-makes-it-easier-to-build-ai-agents-gives-them-verifiable-identities.html) · [Futurum](https://futurumgroup.com/?p=96805)

Announced October 15, AI Passport is a cryptographically signed credential issued through ServiceNow's AI Control Tower that encodes an agent's identity, permitted actions, accessible systems, and accountable owner. Enforcement happens at runtime — an out-of-scope action triggers rerouting, context correction, or a kill switch, with full audit trail. Built on open specifications so third-party identity providers and enforcement points can issue and verify credentials; NVIDIA is a design partner with its Open Agent Safety Platform.

**Why it matters:** Moves AI agent governance from post-hoc audit logs to active runtime enforcement — a critical gap as multi-agent deployments reach production in enterprise settings.

### 4. Notion Rebuilds Agent Harness for Long-Running (24h+) Tasks
**Source:** [AI Agents News — Week of October 22](https://aiagentstore.ai/ai-agent-news/this-week)

Notion reportedly rebuilt its internal agent harness to support tasks that run beyond 24 hours, and added a model router that selects the most cost-appropriate model for each step. No public SDK release was announced; this appears to be an internal platform change surfaced through a product update.

**Why it matters:** Long-horizon agent tasks have been a reliability weak point across most platforms; Notion's move signals that production-grade "set-and-forget" agentic workflows are becoming an expectation rather than an edge case.

## New Framework

### 5. Google ADK v2.12.0 — Graph-Based Execution Engine
**Source:** [AI Agent Frameworks 2026 Update](https://www.morphllm.com/ai-agent-framework) · [Top 9 AI Agent Frameworks October 2026](https://www.shakudo.io/blog/top-9-ai-agent-frameworks)

Google's Agent Development Kit shipped version 2.12.0 (reported October 13), introducing a graph-based execution engine that replaces the earlier sequential task runner. The update is part of ADK's broader push toward stateful, multi-step agent workflows with clearer dependency management between tool calls.

**Why it matters:** A graph-based execution model makes it much easier to build agents with parallel tool calls, conditional branching, and retries without manually orchestrating state — matching patterns already common in LangGraph and competing frameworks.

## Research

### 6. Slot-JEPA — Object-Slot World Model Interface from CAS
**Source:** [AI News Today, October 21](https://aiweekly.co/ai-news-today) · [AI Infrastructure Digest 2026-10-19](https://github.com/duanyytop/agents-radar/issues/3866)

Released October 21 by researchers at the Chinese Academy of Sciences, Slot-JEPA is a world-model interface that splits a frozen V-JEPA encoder's dense patch representations into 16 object slots, enabling structured scene understanding without per-frame supervision. The approach keeps the encoder frozen and learns only the slot decomposition layer on top.

**Why it matters:** Object-centric representations are a long-standing goal in vision models for robotics and agent perception; Slot-JEPA's frozen-encoder approach suggests a lightweight path to structured world models without expensive retraining.

**Why it matters:** Industrial AI agent deployment has lagged behind software-industry adoption; a purpose-built orchestration layer from a major OT vendor suggests the gap is narrowing, with significant implications for factory automation and predictive maintenance at scale.
