## New Agent Tool

### 4. Microsoft Foundry: Agents Get Full Microsoft 365 Identities
**Source:** [AI Agents News — aiagentstore.ai](https://aiagentstore.ai/ai-agent-news/this-week)

Updates announced November 19 let organizations provision AI agents as named Microsoft 365 members with their own Entra identities, email inboxes, calendar, and OneDrive. ### 5. Tether 0.4.0 Adds Agent Run Replay Harness
**Source:** [AI Agents News — aiagentstore.ai](https://aiagentstore.ai/ai-agent-news/this-week)

Released November 22, Tether 0.4.0 introduces a test harness that replays recorded agent runs, letting developers assert which tools were called, check final file states, and verify that the agent respected step or token-budget limits. **Why it matters:** Deterministic replay for agentic workflows is a key missing primitive — this brings familiar CI-style test coverage to multi-step agent pipelines.

### 9. SECURITY: Microsoft's `agent-framework` PyPI Package Compromised (Supply Chain Attack)
**Source:** [Chainguard — Microsoft agent-framework compromised on PyPI](https://www.chainguard.dev/unchained/microsoft-agent-framework-compromised-on-pypi-november-2026) | [DEV Community](https://dev.to/somnath_khadanga_2e5c2364/microsofts-agent-framework-package-was-hijacked-on-pypi-what-ai-saas-teams-should-check-1b4e)

Versions 1.26.1 and 1.26.2 of Microsoft's `agent-framework` PyPI package, published November 17, contained a credential stealer that runs on every Python start. Both versions have been pulled from PyPI. The last clean version is 1.26.0 (November 12). **Why it matters:** This is a high-severity supply chain incident affecting any AI/agent project that updated `agent-framework` between November 12 and the removal date — teams should audit dependencies and rotate any credentials present in those environments.
